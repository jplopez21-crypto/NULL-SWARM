# Machine destruction feedback

Destruction now uses original faceted triangular chips instead of the box used by beams. One cached opaque unit-bounds ArrayMesh has eight triangles (previous box twelve); existing tints use cached unshaded grayscale facet materials. Beam/dash boxes and impact/ring geometry are unchanged. No particles/lights or pool nodes were added. Existing 160-node pool, quality caps 40/85/150, normal counts 2/4/6, doubled large counts, 650 ms flight, gravity, scaling, expiry and RNG order remain. Reduced flashes keeps existing rings and omits destruction chips. This is a structural debris change, not a measured FPS gain.

Six seeded 180-frame synthetic traces were recorded from accepted source ea3fdea9 before replacement, covering all qualities/flash preferences, saturated caps, mixed effect kinds, transforms, lifetimes, recycling and next global RNG value. Mesh topology is intentionally excluded. Current fingerprints and numeric outcomes match; typed field comparison avoids JSON int/float serialization differences. Main normal-game functions, CombatEffects.tick/destruction and SwarmAudio.play/volume/music/memory cue source bodies remain identical.

Kill SFX now uses an original 140 ms three-transient mechanical crunch. Local 32-bit integer noise and body/metal partials are synthesized once per audio node into non-looping 22,050 Hz mono sixteen-bit PCM. It does not consume global/gameplay RNG. The existing kill ID/trigger, twelve shared voices, pitch variation, -12 dB voice mix, 65 ms gate and SFX/Master controls remain. No delayed queue or dedicated new voice is added. Original memory/music/weapon cues are retained. Current cue hash/levels and exported QA WAV are recorded in destruction-tests.json; human listening and speaker mix remain unverified.

Run `godot --headless --script tests/run_destruction_tests.gd`. Coverage includes geometry/material/cache and pool reuse, all quality/reduced-flash counts, exact reference traces, PCM format/headroom/endpoints/RNG, finite one-shot playback, real SFX routing/muting/burst rejection and an actual controlled enemy-damage/death callback with unchanged XP. Existing suites remain in tools/run_headless_checks.py.

Android smoke reads actual active fragment geometry and the registered kill-cue dispatch/PCM digest through the emulator-only read-only probe. It samples ordinary kills, not forced rewards; audio output is disabled in CI and dispatch metadata is not human hearing acceptance. The PCM digest is cached by stream identity, not hashed each frame. Desktop-debug capture adds labelled frozen high-quality and reduced-flash references; ordinary camera/gameplay cannot enter them. New assets remain development artwork/audio; exact current results and artifact identities are in TEST_RESULTS.md.
